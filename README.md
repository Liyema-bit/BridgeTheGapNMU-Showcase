# Bridge the Gap NMU

## Project Overview

**Bridge the Gap NMU** is a collaborative web application developed by a team of four students at Nelson Mandela University.

The platform was designed to help connect verified unfunded students with donors who can provide essential items such as food, clothing, toiletries, and stationery. The system provides a more structured and secure way for students to request and receive assistance compared with relying solely on informal social-media channels.

## Key Features

- Student registration and profile management
- Donor registration and profile management
- Donation listing and management
- Students can view and claim available donations
- Student verification by administrators
- Funding-status management
- Pickup scheduling
- Administrative functionality for managing users and donations
- Validation and error handling throughout the application

The original source-code repository is private because it contains collaborative team work. This public repository is intended solely as a portfolio showcase of the project.


## My Contributions

As part of the four-person development team, I was responsible for designing and implementing several features across the application's notification, reporting, and expiry-management functionality.

My primary contributions included:

- **Notification System:** Implemented notification functionality for students, donors, and administrators, including displaying user-specific notifications and marking notifications as read.
- **Administrative Reports:** Developed functionality that allows administrators to generate Donation Summary, Claims Summary, and Expiry Reports using data retrieved and calculated from the system.
- **Expired Item Management:** Implemented administrative functionality for identifying and removing expired perishable donation items.
- **Automated Expiry Detection:** Contributed to the system process that checks perishable donation expiry dates and flags expired items for administrative action.
- **Administrator Alerts:** Implemented notifications that alert administrators when expired items require attention.
- **UI Integration:** Designed and implemented the interfaces associated with these features and integrated them with the wider Bridge the Gap NMU application.

These features involved working across the application's user interface, business logic, and database-backed functionality while integrating my work with features developed by the other team members.
